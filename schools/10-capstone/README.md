# School 10 — Capstone

**Job:** Personal domain coach agent with citations, daily drills, RTMA sessions.

## Beginner model
You do not “finish AI.” You build a **coach loop** that compounds.

## Acceptance (future GREEN)
1. Cold-start docs exist for a stranger  
2. 20+ citation-required questions pass  
3. Injection tests fail closed  
4. Weekly report generates without secrets  
5. Friend can run happy path  

## Suggested domains
- UC / voice (use free UC university corpus)  
- Networking  
- Your professional notes (scrubbed)  
- Language learning  
- Personal research library  

## Order
Foundations → tools → evals → RAG → (optional) voice → share.  
Do not costume a capstone before Phase 1 GREEN.

## RTMA
Every coaching session writes Run/Trace/Metric/Artifact. No session, no claim.

## Portfolio-grade acceptance

- [ ] Stranger completes cold start without the author
- [ ] 25+ versioned golden tasks and adversarial probes run
- [ ] Retrieval and generation have separate metrics
- [ ] Empty evidence returns no grounded answer
- [ ] Tools are typed, allowlisted, bounded, and replayable
- [ ] Side effects require a named human approval artifact
- [ ] Quality, p95, cost per passed task, and safety escapes are reported
- [ ] Prompt/model/index changes run the suite before promotion
- [ ] Rollback is rehearsed, not merely written
- [ ] Portfolio shows one failure, correction, and decision

Final deliverables: one-page architecture, runnable code, scorecard, runbook,
scrubbed demo, and RTMA bundle. Review the result again at 30 and 90 days.

## 2026 capstone depth

- Demonstrate one local route and one optional frontier route behind the same contract.
- Include RAG retrieval metrics, citation checks, and explicit no-evidence behavior.
- Show a bounded tool loop with trace ids, approval policy, correction, and hard stop.
- Evaluate at least one multilingual, accessibility, privacy, and adversarial fixture.
- Report quality, p95 latency, cost per verified task, safety escapes, and recovery time.
- Finish with a cold learner replay, signed decision record, and rehearsed rollback.
