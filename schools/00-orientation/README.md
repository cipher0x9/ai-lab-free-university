# School 00 — Orientation

**Job:** Map, honesty counters, safety, hardware reality.  
**For:** general public free learners (domain experts, engineers, students).

## Beginner model
AI is a system with failure modes. If you can learn networks, medicine ops, voice, or code — you can learn this with evidence habits.

## Who can enroll
- Domain experts new to AI  
- Local-lab builders  
- Engineers shipping agents  
- Students / career switchers  

Author background (UC/Cisco) is a bridge and sibling pack — **not** a prerequisite.

Hype without proof · key leak risk · giant HTML as only path · skipping evals.

## RTMA
**Run** verify script · **Trace** console+artifacts · **Metric** pass_rate + HTML size · **Artifact** reports + GREEN ticks.

## Interview 30 / 90
**30s:** I learn AI with RTMA — proof over vibes — free pack anyone can open.  
**90s:** Phase 1 is hello→tool→eval→GREEN with zero keys. Mock brain allowed if local server is down. Secrets never ship. UC free pack is a sibling, not a dependency.

## 90-day launch contract

Write one sentence for your domain, one task you can score, and one action the
system must never take without approval. Create folders for `fixtures/`, `runs/`,
`traces/`, `metrics/`, and `reports/`. Your first artifact is a baseline, even if
the answer is bad.

**Week-1 proof:** five runs, one forced failure, one correction, one teach-back.
**Falsifier:** if a stranger cannot replay the command, the campus is not yet your lab.

## 2026 orientation practice

- Write the user, task, data boundary, and “never autonomously” action before choosing a model.
- Define one deterministic success check and one human-quality rubric for the task.
- Record the cheapest local route that can teach the mechanism without an account.
- Name the frontier boundary you may test later and what evidence would justify it.
- Give every experiment a time, turn, and cost cap before Run begins.
- GREEN means a stranger can reproduce the baseline and explain its limits.
