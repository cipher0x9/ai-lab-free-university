## About “big / 600MB” files (important & honest)

| Question | Answer |
|----------|--------|
| Can friends download a **full working free university**? | **Yes** — use the **small Release zip** above. That is the supported free share. |
| Are multi-hundred-MB HTML archives on public GitHub? | **No by design** on the public free repos. Huge single HTML files freeze browsers and are hard to host safely. |
| Where do large local archives live? | **Optional on your Mac Mini only** (power-user local copies). Not required for free learners. |
| Will clone break someone’s machine? | **No** — public clone is the **browser-friendly tree**, not a 600MB bomb. |
| Can they “install an app”? | This is **not** a signed App Store app. It is an **offline HTML university + optional Python labs**. Open HTML = use. |

**Safe rule we follow (both free packs):**

1. Default free share = **small, browser-friendly**  
2. Optional huge files = **local / clearly labeled**, never the only path  
3. **No secrets, no customer data, no model weights** in git  
4. Educational only — pin vendor docs for production
