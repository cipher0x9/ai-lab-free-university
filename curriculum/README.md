## 3. Modular Module Summaries & Learning Outcomes

### 3.1 Foundational Modules
- **`MACHINE-LEARNING-FOUNDATIONS.md`**: Matrix decomposition, SGD/Adam optimization, loss functions, bias-variance decomposition.
- **`LLM-ARCHITECTURE-DEEP.md`**: FlashAttention v1/v2/v3, RoPE embeddings, KV-cache math, GQA vs MHA, speculative decoding.

### 3.2 Fine-Tuning & Application Modules
- **`FINE-TUNING-AND-PEFT.md`**: LoRA/QLoRA math, rank decomposition, DPO loss formulations, GRPO relative reward calculation.
- **`RAG-SYSTEMS-DEEP.md`**: HNSW graphs, Reciprocal Rank Fusion (RRF), cross-encoder reranking, parent-child chunking.
- **`AGENT-ARCHITECTURE.md`**: Bounded ReAct loops, stateful graphs, tool calling schema validation, microVM execution.

### 3.3 Production & Operations Modules
- **`EVAL-AND-OBSERVABILITY.md`**: LLM-as-a-Judge bias mitigation, Ragas metrics, tracing pipelines, hallucination benchmarks.
- **`AI-SECURITY-SAFETY.md`**: Jailbreak defenses, adversarial prompt injection mitigation, red-teaming, guardrails.
- **`MLOPS-AND-PRODUCTION.md`**: Distributed model serving, vLLM continuous batching, Tensor Parallelism, Ray clusters.
- **`COMPUTER-VISION-AND-MULTIMODAL.md`**: Vision Transformers (ViT), cross-attention projections, diffusion models.
- **`NLP-AND-SPEECH.md`**: BPE tokenizers, ASR Whisper architecture, alignment protocols.

### 3.4 Career & Frontier Execution
- **`AI-ENGINEERING-INTERVIEWS.md`**: 100+ interview Q&A cards spanning theory, systems, RAG, agents, and system design blueprints.
- **`AI-CAREER-2026.md`**: 2026 skill matrix tiers, gold-standard open-source portfolios, compensation benchmarks.
- **`FRONTIER-RESEARCH-2026.md`**: Test-time compute scaling, sub-quadratic SSMs, BitNet ternary quantization, edge AI.
