# School 00 — Orientation

**Job:** Map, honesty counters, safety, hardware reality.  
**For:** general public free learners (domain experts, engineers, students).

## Beginner model
AI is a system with failure modes. If you can learn networks, medicine ops, voice, or code — you can learn this with evidence habits.

## Who can enroll
- Domain experts new to AI  
- Local-lab builders  
- Engineers shipping agents  
- Students / career switchers  

Author background (UC/Cisco) is a bridge and sibling pack — **not** a prerequisite.

## Mechanism
| Idea | Plain meaning |
|------|----------------|
| Local model | Brain on your machine |
| Cloud model | Rented brain with keys + cost |
| Agent | Loop with tool privileges |
| Eval | Fixed tests vs vibes |
| Free pack | Stranger can open offline |
