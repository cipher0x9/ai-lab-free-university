# Open-Source Models Landscape (2026 Learner Map)

**CYPHER0X9 · AI Lab Free University · curriculum pack · MIT**  
**Note:** Names and ranks move monthly — learn the **selection method**, not a hype list.

---

## 1) Selection method

1. Define task + language + context need  
2. Set latency/cost/privacy constraints  
3. Shortlist 2–3 models  
4. Run **your** golden eval  
5. Pin winner by digest  

---

## 2) Axes to score

| Axis | Question |
|------|----------|
| Quality | Eval score on your set |
| Speed | tokens/s or first token |
| VRAM / RAM | Will it fit? |
| License | Can you use commercially? |
| Tool use | Does it follow schemas? |
| Multilingual | Real or marketing? |

---

## 3) Local quant tradeoffs

Lower quant → smaller/faster, possible quality loss. Measure; don't folklore.

---

## 4) Frontier vs local

| Use local | Use frontier |
|-----------|--------------|
| Private data | Hard reasoning |
| Offline | Multimodal edge cases |
| Cost control | Best tool use (sometimes) |

Adapters make switching cheap.

---

## 5) Ethics

Respect model licenses and data provenance. No scraped private customer dumps.
